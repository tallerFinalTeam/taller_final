Taller Final - Sistema de Gestión de Biblioteca

Aplicación de escritorio en Java con interfaz gráfica (Java Swing) para gestionar
el catálogo de la Biblioteca Municipal San Rafael. Permite registrar libros,
mostrar el catálogo completo, filtrar por autor y eliminar libros.

Integrantes

- Wilmar Martinez, Juliana Parra, Jacobo Camacho

Funcionalidades

- Registrar un nuevo libro (con validación de campos obligatorios y de ISBN duplicado)
- Mostrar todos los libros del catálogo
- Filtrar libros por autor
- Eliminar un libro (con confirmación previa)

Tecnologías y conceptos aplicados

- Java (POO: encapsulamiento, herencia/polimorfismo)
- Java Swing (JFrame, JTable, JButton, JTextField, ActionListener)
- Estructuras de datos: ArrayList, HashMap


Estructura del proyecto

- `Libro.java` — Clase modelo que representa un libro.
- `Biblioteca.java` — Clase que administra la colección de libros (agregar, eliminar, filtrar).
- `VentanaPrincipal.java` — Interfaz gráfica de la aplicación.
- `Main.java` — Punto de entrada de la aplicación.
